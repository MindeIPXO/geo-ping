Browser location fallback demo

This page first asks for precise browser geolocation. If the user declines, it does not try to bypass that choice. It can optionally perform a much less precise IP-based lookup after the user clicks the fallback button.

Important: JavaScript running in a browser cannot send ICMP ping packets. Latency-based “triangulation” from browser fetch timings is unreliable and can be misleading because routing, CDNs, VPNs, NAT, carrier networks, and CORS behavior distort measurements.

IP fallback uses https://ipapi.co/json/ as a demo endpoint. For production, use your own backend or a paid geolocation provider with a data-processing agreement, rate limits, logging policy, and clear user notice.
